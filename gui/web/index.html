레이블링 클래스·색상

설정은 현재 출력 폴더에 저장됩니다. 이름과 색상을 바꾸거나 클래스를 추가·제거할 수 있습니다.

제거는 새 레이블링 대상에서 제외하는 동작입니다. 기존 박스·픽셀·ID는 유지되며 아래에서 복원할 수 있습니다. 배경 0과 ignore 255는 필수 값입니다.

Bounding box

Segmentation

마스크는 클래스 ID를 저장하는 단일 채널 PNG입니다. 색상 변경은 시각화에만 적용됩니다. 배경 0은 RGB가 보이도록 투명하게 표시합니다.

승인 데이터 추출

저장된 승인 프레임 전체를 새 폴더에 복사합니다. 화면의 선택·검색 필터와 관계없이 승인된 데이터만 포함합니다.

train/test → 입력 그룹별로 시퀀스를 합치고, manifest 순서·타임스탬프순으로 000001부터 번호를 매깁니다. 원래 시퀀스·파일명은 manifest에 보존합니다.

RGB와 승인된 segmentation·bounding box·검수 기록을 복사합니다. NIR·깊이·카메라 정보는 입력에 있는 경우 함께 복사합니다. 기존 폴더는 덮어쓰지 않습니다.

추출 중 창을 닫아도 복사는 계속됩니다. 완료 전에는 출력 폴더를 사용하지 마세요.

레이블링 작업 폴더

입력 이미지는 변경하지 않고 편집 라벨·백업·작업 manifest를 출력 폴더에 저장합니다.

이미지 폴더 또는 manifest.csv가 있는 데이터셋을 지원합니다. RGB만 있어도 수동 편집과 SAM을 사용할 수 있습니다. 출력 폴더는 새로 만들어도 됩니다.

서버 폴더 선택

Pseudo labeling

현재 입력 폴더의 프레임을 선택한 모델로 처리합니다. 검수 대기 라벨을 새 출력 폴더에 저장합니다.

공동 모델은 호환 YOLO26 joint 가중치와 yolo26s.pt 템플릿이 필요합니다.

requirements-pseudo.txt가 설치된 Python을 지정하세요. GUI 자체는 모델 패키지가 없어도 실행됩니다.

세그멘테이션 모델은 마스크를, 검출 모델은 박스를 생성합니다. 다른 작업의 라벨은 초기값으로 남습니다. 기존 라벨과 입력 데이터는 덮어쓰지 않습니다. 모델 가중치는 별도로 넣어야 합니다.

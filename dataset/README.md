Place RGB images here, or choose an existing server folder in the GUI. Nested folders are supported.

Optional RGB/NIR pairs: `sequence/images/000001.png` and `sequence/nir/000001.png`.
A DY-style `manifest.csv` is also supported. Its file paths are relative to the input folder.

Input images are read only. Manifests and editable labels are written to the selected output folder.
